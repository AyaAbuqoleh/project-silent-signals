# project-silent-signals

Silent Signals: موقع/منصة تفاعلية للتواصل غير الصوتي (مورس ولغة الإشارة).

## المجلدات
- /src/Api             ASP.NET Core Web API
- /src/Domain          نماذج الكيان والمنطق العام (بدون اعتماديات بنية تحتية)
- /src/Infrastructure  EF Core والربط بقاعدة البيانات
- /frontend            واجهة HTML/CSS/JS (Vite + Vanilla)
